How to use a list
  1. Make sure the AnKing deck is installed and synced through AnkiHub.
  2. Click Copy search on the lecture or IBRA you want. IBRA lists search by AnKing's UWorld tags instead of card IDs.
  3. In Anki, open Browse, paste into the search bar, and press Enter.
  4. Select all cards (Ctrl/⌘+A), then toggle suspend (Ctrl/⌘+J). Check that the cards are no longer yellow.

Let's Go Streak

Hype pop-up for a streak of Good answers
v1 · 6 KB
LETS F***ING GO10 Good in a row
  • Hit Good 10 times in a row and a big banner pops up over Anki. It fires again at 20, 30, and so on.
  • Easy also counts. Again or Hard resets the streak to zero.
  • The banner stays up until you answer the next card, or you can click it to close it. It doesn't steal focus, so your answer keys keep working.
  • Add your own picture or GIF and it shows above the banner (steps below).
How to install
  1. Click Download add-on. You'll get lets_go_streak.zip.
  2. Rename it so it ends in .ankiaddon instead of .zip (for example lets_go_streak.ankiaddon). On Windows, turn on file name extensions first so it doesn't end up as .ankiaddon.zip.
  3. Double-click the file, or in Anki go to Tools → Add-ons → Install from file… and pick it.
  4. Restart Anki. Let's Go Streak should be listed under Tools → Add-ons.
  5. To test quickly, open Tools → Add-ons → Config, set streak_target to 2, do a few reviews, then set it back to 10.
Add your own hype image or GIF
  1. In Anki, go to Tools → Add-ons, select Let's Go Streak, and click View Files.
  2. Drop your image into that folder and name it exactly hype.gif (or hype.png / hype.jpg). On Windows with hidden extensions, name it just hype.
  3. No restart needed. It shows up on your next streak, and GIFs animate.
Settings
  1. Change these under Tools → Add-ons → Config:
  2. streak_target: how many Good answers in a row (default 10)
  3. count_easy: whether Easy counts toward the streak
  4. repeat_every_streak: pop up at every multiple (10, 20, 30) or only once
  5. popup_ms: 0 keeps it up until your next answer; a number of milliseconds also closes it on a timer
  6. text: the banner text, if you want something cleaner for the library
